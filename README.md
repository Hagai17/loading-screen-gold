A tiny Python program that writes one loading-screen tip to `/output/entry.txt`: a single line of at most 200 characters — the sharpest, funniest tip a tired developer and an AI coding agent could read mid-build. The line was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — a real loading-screen tip for stressed developers and AI coding agents rather than a slogan, a real laugh through a turn rather than a groan pun, economy of words, both audiences feeling the joke is about them at once, and fresh rather than a rerun of the coffee, deadline or compile jokes. The winner pins the agent's signature failure — hallucinating progress — on whichever of the two is actually stuck, and springs it on the reader last: check the model first, then check yourself. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
